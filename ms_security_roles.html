👥 Microsoft Security Roles Reference

A comprehensive reference for Microsoft Entra ID built-in security roles — covering permissions, scope, and typical use cases for security architects and administrators.

Role Name ↕ Category ↕ Key Permissions Typical Use Case
Security Administrator Identity
  • Manage security policies
  • View security alerts
  • Configure MFA settings
  • Manage Conditional Access
 Day-to-day security operations, policy configuration, and alert triage across M365 and Entra ID.
Security Reader Identity
  • Read-only security settings
  • View security alerts & reports
  • Read Secure Score
 Auditors, compliance reviewers, and stakeholders who need visibility without change authority.
Global Administrator Identity
  • Full tenant control
  • Manage all admin roles
  • Access all resources
  • Reset any password
 Break-glass accounts and tenant bootstrapping. Should be heavily restricted and monitored via PIM.
Privileged Role Administrator Identity
  • Manage PIM assignments
  • Configure role settings
  • Approve activation requests
 Managing who has access to privileged roles, enforcing just-in-time access controls.
Privileged Authentication Administrator Identity
  • Reset MFA for all users
  • Manage authentication methods
  • Register/deregister devices
 Authentication hygiene — managing MFA registrations, SSPR, and authentication method policies.
Conditional Access Administrator Identity
  • Create/edit CA policies
  • Manage named locations
  • Configure sign-in risk policies
 Designing and maintaining conditional access policies to enforce contextual access controls.

Role Design Principles

🔑 Principle of Least Privilege

Assign the most specific role that fulfills the requirement. Avoid Global Administrator when Security Administrator will suffice. Scope to a single resource or resource group where possible.

Core Zero Trust Principle

⏱️ Just-In-Time Access with PIM

Use Privileged Identity Management (PIM) to make all privileged role assignments eligible rather than permanent. Require approval, justification, and time-bounds for activation.

Microsoft Entra PIM

🔍 Continuous Access Reviews

Schedule recurring access reviews for privileged roles using Identity Governance. Auto-remediate stale assignments and remove roles when no longer needed.

Entra Identity Governance

🚨 Break-Glass Accounts

Maintain two Global Administrator break-glass accounts that are cloud-only, MFA-exempt, and monitored by high-priority alerts. Exclude from all Conditional Access policies.

Business Continuity

📋 Role Separation

Separate Security Administrator and Compliance Administrator duties. A single person controlling both security posture and audit logs creates an insider threat risk.

Separation of Duties

🏢 Administrative Units

Use Administrative Units to scope role assignments to specific departments, regions, or subsidiaries — preventing lateral movement through over-privileged helpdesk accounts.

Entra Administrative Units
